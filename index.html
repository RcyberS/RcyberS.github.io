How I work

My approach is hands-on: I don't just manage security operations; I also design, build, integrate, improve, and operationalize the technologies, intelligence capabilities, and processes behind them.

  1. BuildThe whole stack, from deploying the tools to the detection rules, threat intelligence and monitoring.
  2. LeadDaily security operations and incident investigations, with the team.
  3. Write it downIR playbooks, runbooks, detection use cases and response workflows, so the team handles each incident the same way.
  4. AlignPolicies and procedures with ISO 27001 and NIST, and detection coverage measured against MITRE ATT&CK.
