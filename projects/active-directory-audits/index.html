CASE-04

Active Directory audits and hardening

A repeatable audit cycle based on the ANSSI method: collect, score, fix, re-scan, including for a healthcare group.

Status
Recurring audit cycle
My role
Auditor and hardening lead
Where
AVEOLYS clients, including a healthcare group
When
Since 2023
Tools
ORADAD, PingCastle, BloodHound

Why Active Directory

In most companies, whoever controls Active Directory controls everything. Attackers know it, so the domain is the first thing I audit.

The cycle

  1. Collect
  2. →
  3. Score
  4. →
  5. Fix
  6. →
  7. Re-scan
  • Collect: run ORADAD, the collection tool from the ANSSI (France's national cybersecurity agency), on the domain.
  • Score: read the ANSSI report, then use PingCastle and BloodHound to see the attack paths to admin accounts.
  • Fix: write a remediation sheet for each finding, covering privileged accounts, Kerberos settings, services on domain controllers and legacy systems, and plan it with the client's IT team.
  • Re-scan: run the audit again and track every finding until it is closed.

Healthcare

For a healthcare group, the work followed France's CaRE program for hospitals: Active Directory audit, hardening and a review of what is exposed to the Internet.

Clients and findings stay confidential.
