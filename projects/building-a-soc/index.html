Building a SOC from scratch

A full detection and response platform: SIEM, automated case handling and threat intelligence, now watching 62 endpoints and servers.

Starting point

When I joined AVEOLYS in July 2023, the company had no Security Operations Center. Logs stayed on each server and nobody was alerted when something went wrong.

What I built

I deployed Wazuh as the SIEM, with a user-behavior analytics layer, and connected it to an automated pipeline:

  1. Wazuh
  2. →
  3. Shuffle
  4. →
  5. TheHive
  6. →
  7. Cortex + MISP
  • Every alert at level 10 or above is sent to Shuffle, which removes duplicates and opens a case in TheHive.
  • The IP addresses, hashes and domains in the alert are added to the case as observables, with TLP and PAP levels.
  • Cortex and MISP enrich those observables with what is already known about them, before an analyst opens the case.

What it covers

The platform monitors 62 endpoints and servers. It also collects logs from the Zimbra mail server, the web application firewall, Microsoft 365 and Active Directory, with Sysmon on Windows machines.

Result

One chain from a raw log to a qualified case. Analysts start their work with the context already attached, instead of searching for it by hand.
