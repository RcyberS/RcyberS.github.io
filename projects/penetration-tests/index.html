How I work

  1. Scope
  2. →
  3. Discovery
  4. →
  5. Testing
  6. →
  7. Report
  8. →
  9. Follow-up
  • Scope: agree with the client on what is tested, when, and what is off limits.
  • Discovery: map the exposed services and scan for known vulnerabilities with OpenVAS.
  • Testing: test the internal network and Active Directory the way an attacker would, including Kerberoasting and Pass-the-Hash, with BloodHound, Impacket and Mimikatz.
  • Report: each finding is explained with its risk and a fix, ordered by priority.
  • Follow-up: help the client's team apply the fixes, then check them.

Findings belong to each client and are never published here.
