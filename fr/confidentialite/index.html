Politique de confidentialité

Dernière mise à jour : 2026-11-19.

Responsable

Ce site est édité par Stephanio RAZARISON, Antananarivo, Madagascar. Pour toute question sur vos données, écrivez à rbienvenustephanio@gmail.com.

Cookies

Ce site utilise des cookies pour les statistiques de visite avec Google Analytics, jamais pour la publicité.

Préférences enregistrées dans votre navigateur

Si vous changez le thème ou la langue, votre choix est enregistré dans le stockage local de votre navigateur (clés theme et lang) pour que le site s'en souvienne. Il ne quitte jamais votre appareil. Vous pouvez le supprimer en effaçant les données du site dans votre navigateur.

Hébergement

Le site est hébergé par GitHub Pages (GitHub, Inc., États-Unis). Comme tout hébergeur, GitHub traite des données techniques, comme votre adresse IP, pour servir les pages et sécuriser le service. Voir la déclaration de confidentialité de GitHub (s'ouvre dans un nouvel onglet) (en anglais).

Statistiques de visite (Google Analytics)

J'utilise Google Analytics 4 pour compter les visites et voir quelles pages sont lues, depuis quel pays et sur quel type d'appareil. Google Analytics dépose les cookies _ga et _ga_*, valables jusqu'à 2 ans. Google n'enregistre ni ne conserve les adresses IP dans Google Analytics 4. Les données sont conservées 14 mois, puis supprimées.

Les données sont traitées par Google (Google Ireland Limited pour les visiteurs en Europe, Google LLC aux États-Unis). Google LLC est certifiée au titre du cadre de protection des données UE-États-Unis (Data Privacy Framework). Voir les règles de confidentialité de Google (s'ouvre dans un nouvel onglet) et la page sur l'utilisation des données par Google sur les sites partenaires (s'ouvre dans un nouvel onglet).

Vous pouvez bloquer ces cookies dans les réglages de votre navigateur, ou installer le module de désactivation de Google (s'ouvre dans un nouvel onglet).

Me contacter

Si vous m'écrivez par e-mail, j'utilise votre message uniquement pour vous répondre, je ne le partage pas, et je le supprime dans les 24 mois suivant notre dernier échange.

Liens vers d'autres sites

Les liens vers LinkedIn et Upwork ouvrent ces services, qui appliquent leur propre politique de confidentialité.

Vos droits

Vous pouvez demander à consulter, corriger ou supprimer les données personnelles que je détiens sur vous en écrivant à rbienvenustephanio@gmail.com. Je réponds sous un mois. Si vous êtes dans l'Union européenne, vous pouvez aussi saisir votre autorité de protection des données (en France, la CNIL).
