CASE-04

Audits et durcissement Active Directory

Un cycle d'audit reproductible selon la méthode de l'ANSSI : collecter, évaluer, corriger, réévaluer, notamment pour un groupe de santé.

Statut
Cycle d'audit récurrent
Mon rôle
Auditeur et responsable du durcissement
Où
Clients d'AVEOLYS, dont un groupe de santé
Quand
Depuis 2023
Outils
ORADAD, PingCastle, BloodHound

Pourquoi Active Directory

Dans la plupart des entreprises, qui contrôle Active Directory contrôle tout. Les attaquants le savent : le domaine est donc la première chose que j'audite.

Le cycle

  1. Collecter
  2. →
  3. Évaluer
  4. →
  5. Corriger
  6. →
  7. Réévaluer
  • Collecter : lancer ORADAD, l'outil de collecte de l'ANSSI, sur le domaine.
  • Évaluer : lire le rapport de l'ANSSI, puis utiliser PingCastle et BloodHound pour voir les chemins d'attaque vers les comptes d'administration.
  • Corriger : rédiger une fiche de correction pour chaque constat (comptes à privilèges, paramètres Kerberos, services sur les contrôleurs de domaine, systèmes obsolètes) et la planifier avec l'équipe IT du client.
  • Réévaluer : relancer l'audit et suivre chaque constat jusqu'à sa fermeture.

Santé

Pour un groupe de santé, le travail a suivi le programme CaRE pour les établissements de santé en France : audit Active Directory, durcissement et revue de l'exposition sur Internet.

Les clients et les constats restent confidentiels.
